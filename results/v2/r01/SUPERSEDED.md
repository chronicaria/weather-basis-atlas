# Superseded R01 run

This directory holds an earlier R01 run scored over 46 seasons, including 2026.
It is **not** the accepted comparison and must not be cited: it reports 6,865
records where prior-best selection beat the nearest station, against the
accepted 6,355.

The accepted matched comparison is the content-addressed shard under
`var/shards/v2/atlas.evaluate/`, which the release lock pins and the public
county summaries project. `results/v2/r01-candidate/` holds the protocol that
the public research record cites; see the note in that directory about its
paired-loss column.

Retained as history, as the project keeps superseded candidates rather than
deleting them.
